# bltdreeg web

The customer web app for bltdreeg (بلتدريج), a live queue for barbershops in Egypt.

```bash
pnpm install
pnpm dev   # http://localhost:3213
```

Start with [AGENTS.md](AGENTS.md). Deeper docs are in [docs/](docs/): [business](docs/business.md), [domain rules](docs/domain.md), [architecture](docs/architecture.md).
